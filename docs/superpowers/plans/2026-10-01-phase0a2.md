# Phase 0-A2 Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` to carry out the static investigation and relocation steps below. User constraints override compile/build/test and commit steps in general workflows.

**Goal:** 자체 코드의 Legacy/Planned-Legacy 참조를 다시 확인하고 동작 변경 없이 가시성을 높인다.

**Architecture:** 기존 파일과 `.meta`를 함께 이동한다. 혼합 책임 파일과 불확실한 코드는 이동하지 않고 보고한다. 새 런타임 코드나 아키텍처는 만들지 않는다.

**Tech Stack:** Unity C# 및 Unity YAML의 정적 조사, SHA-256 비교, Git diff.

**Spec:** 사용자 첨부 `0f76afcf-39ce-46bd-bd18-285950f6a760/붙여넣은 텍스트.txt`와 이번 메시지의 검증 제한.

## Global Constraints

- Compile/Player Build/Server Build/restore/패키지 및 환경 수정 금지.
- `.meta`와 파일 내용, namespace/API 및 special-folder 소속 보존.
- 코드 삭제, 기능 제거, 로직 재작성, 데이터/JSON/ID/서버/DB 변경 금지.
- ThirdParty 제외. 서버는 조사·보고만 한다.
- 기존 Phase 0-A 변경을 유지하고 stage/commit하지 않는다.

## Review Focus

- GUID 및 Inspector/Event 참조는 단순 텍스트 호출 0보다 우선한다.
- reflection/string type 생성 및 Unity lifecycle 자동 호출을 고려한다.
- Planned-Legacy는 현재 필요한 코드이며 Unused로 취급하지 않는다.
- 클래스 전체가 혼합 책임이면 메서드 수준 후보로 보고한다.
- git HEAD와의 기존 대규모 이동을 이번 변경과 혼동하지 않는다.

## Decisions

Ruling: 런타임 코드 테스트·컴파일·빌드 대신 사용자가 지정한 정적 비교만 수행한다. 커밋/새 아키텍처/기존 코드 재작성은 하지 않는다.

Ruling: 직접 참조가 없는 Player1 전용 행동은 문자열 reflection 입력을 배제할 수 없어 위치를 유지한다. `(Past)P01`은 Bundle membership 때문에 미사용으로 확정하지 않는다.

Result: 자체 C# 167개 조사, 기존 파일 48개 이동(21 C#), 전체 원본 asset bytes/GUID 보존. A–G 보고서는 `docs/phase0a2/REPORT.md`.
